핑크냥 튜브타임이란?

아이들의 건강한 미디어 습관을 위해 만들어진 가족용 앱입니다. 독서를 하면 유튜브 시청 시간이 충전되는 재미있는 보상 시스템으로, 아이들이 스스로 책을 읽고 싶어하게 만들어요!

주요 기능

• 독서 시간에 따른 유튜브 보너스 시간 자동 계산
• 가족 코드로 부모-자녀 간 데이터 공유
• 캘린더로 독서 기록 한눈에 확인
• 귀여운 고양이 캐릭터로 재미있는 경험

이렇게 사용하세요

1. 부모님이 로그인하여 가족 코드 생성
2. 아이들에게 가족 코드 공유
3. 아이가 책을 읽으면 제목과 쪽수 입력
4. 자동으로 계산된 유튜브 시간 확인!

2. 개인정보의 이용 목적
수집된 정보는 서비스 제공, 가족 간 데이터 공유, 사용자 식별 목적으로만 사용됩니다.

개인정보는 Firebase 클라우드에 안전하게 저장되며, 사용자 요청 시 삭제됩니다.

4. 제3자 제공
수집된 개인정보는 제3자에게 제공되지 않습니다.

1. 서비스 목적
